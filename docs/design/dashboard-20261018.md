# 共通ダッシュボードのデザイン

目的：使用率を読む、選出を予想する、すばやさを調整する操作を、定番の分析ツールの構成で分かりやすくする。

## 見た目の基準

- 背景 `#f5f7fb`、カード `#ffffff`、文字 `#172b4d`、補助文字 `#475569`、アクセント `#2563eb`、境界 `#e2e8f0`。
- 既存のInter／日本語フォントを使用。本文14px、見出し28px、カード見出し16px。字形やデータは変更しない。
- PCは上部ナビ、ルール、ページ見出し、要点、詳細の順。モバイルは画面下の5項目ナビ。
- 左揃えの見出し、数字の桁揃え、12pxのカード角丸。装飾グラデーションと透過ガラスは使わない。
- 自分チームは左・上、相手は右・下。初期ポケモンはアシレーヌを維持。

## グラフ

Chart.js 4.5.1のUMD配布物を `site/vendor/chart.umd.min.js` に同梱（MITライセンスを併記）。
取得元：`https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.min.js`。

- 推移は最新上位6匹を色分けし、凡例で切替。レギュレーション境界で線を切り、破線と名前を表示する。
- 散布図は使用率と選出率。点のラベル、詳細のツールチップ、クリックで詳細へ。95%範囲と母数は表にも残す。
- 全グラフに読み上げ名を付ける。Canvasの推移・散布図にはHTML表を用意する。
- 描き直し前にインスタンスを破棄し、明暗切替・リサイズにも対応。Chart.jsを読めない場合は従来SVGを使用。
- `dashboard.css` とグラフJSも公開ビルド時に内容ハッシュを付けて配信。

## 検証

Python既存テスト、Nodeの予測・ミラー・グラフ契約テスト、6画面のPC／モバイル表示と主要操作を確認する。
フォント配信方式は既存のサブセット・同一ドメイン配信を維持。Core Web Vitalsの実ユーザー値は未計測。

2026-10-18の確認結果：Python66件、Node11件、ブラウザー57項目が成功。6画面を1440px／390pxで確認し、明暗の表示、検索、推移切替、すばやさ入力、チーム配置、信頼区間の保持を検証。画面遷移・リサイズ時のJavaScript例外は0件。
Chart.jsの遅延リサイズ更新が破棄済みCanvasに走る問題を修正し、ルート切替前に全インスタンス、詳細の再描画前に既存グラフを破棄する。
